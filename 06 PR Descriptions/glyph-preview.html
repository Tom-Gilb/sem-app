Three glyph families — semantically orthogonal (Tom 2026-06-04):
1. Color Glyphs identify a Planguage ENTRY TYPE (Function / Value / Solution / Constraint / Resource / Stakeholder / Evo-Step / Task).

3. Nav Tab Glyphs identify a VIEW / WORKSPACE.
Never use a Keyed Action Glyph for an entry type. Never use a Color Glyph for an action. THIS IS OK (Tom verbatim).

▶ Analyze-Spec Compound Glyphs — [TYPE]→? — 7 SHIPPED (2026-06-05)

The pattern [*]→? means "analyze a spec entry" — a spec item inside brackets, a transformation arrow, and a question mark (insight/analysis result). The * can be replaced with the specific type icon. These are compound glyphs — the outer [ ] brackets (slate) act as the entry-type container; the inner mini icon identifies WHICH type is being analyzed; the cyan → is the transformation (analysis happening); the violet ? is the result (insight, question answered).
ALL 7 SHIPPED. Master dispatcher: AnalyzeTypeIcon.vue (plType prop → correct compound glyph). Tom approved 2026-06-05.

▶ OptimaGlyph — Balancing Critical Values (SHIPPED 2026-06-05)

Inspired directly by the OPTIMA book cover (Tom Gilb 2024): "A system of values and resources in reasonable balance." Three horizontal threshold lines (Stretch blue dashed / Goal olive solid / Tolerable dark brown, thickest) with colored dots above Goal (green = meeting target), a yellow warning circle (approaching Tolerable), and a red downward triangle (violation = below Tolerable). International symbols only: dots, lines, universal colors — no English letter abbreviations (DD-015). Diagrammatic glyph family — a conceptual diagram, not a keyed-character icon (Tom-ratified OPTIMA book cover recreation). Used as the pin icon for Stage 10 Pin 4 "Potential Resource Optimization" and as the mini-diagram in the ResourceOptimaPanel.vue header strip.

Concept Source OptimaGlyph (SHIPPED — OptimaGlyph.vue) Element-by-element semantic encoding
Optima Balance OPTIMA book cover diagram (Gilb 2024)
"Balancing Critical Values"		 ── Stretch line (blue dashed): aspirational ceiling — above Goal, rarely reached. Stretch violations impossible (you can always be above Stretch).

── Goal line (olive solid): declared Goal for each V. entry. Green dot above this line = on-track.

── Tolerable line (dark brown, thickest): hard minimum. Crossing below = Constraint Violation. The OPTIMA tool shakes this entry in red continuously.

● Green dots: values currently at or above Goal. Multiple dots = multiple V. entries simultaneously on-track.

◉ Yellow circle: value between Goal and Tolerable — caution zone. OPTIMA tool shows orange status. "Potential Resource Optimization" prompt applies here.

▼ Red downward triangle: value below Tolerable = active violation. Triggers red shake animation + violation banner in OPTIMA tool. "Fix violations" button restores to tolerablePos+5.

DEEP Planguage theory (Optima book + Tom Gilb 2026-06-05): A resource can be increased in budget while others are decreased or held constant, in order to buy more values or less constraint pressure. The OPTIMA tool makes this trade-off visible: adjusting one resource slider propagates impact across all V. entries via the V×C ratio matrix. This is not "spend less" — it is "balance optimally." See also: DEEP Planguage book (Gilb), Optima book (Gilb 2024).
